# AI Workplace Productivity Assistant

## Project Overview

**AI Workplace Productivity Assistant** is a modern, responsive SaaS-style web application designed to help professionals complete common workplace tasks using artificial intelligence.

The application provides AI-powered tools for generating professional emails, researching and summarising content, and interacting with an AI workplace assistant. The system is designed as a frontend-only application and does not store user data.

## Features Implemented

### ✉️ Smart Email Generator

* Generate professional workplace emails using AI.
* Supports **Formal, Friendly, and Persuasive** tones.
* Users provide the context and key information for the email.
* AI dynamically generates responses based on the user's input.
* Generated emails can be edited before use.

### 🔎 AI Research Assistant

* Research a topic using an AI-generated response.
* Paste article text or a URL for analysis.
* Generate AI-powered summaries.
* Extract key insights.
* Provide practical recommendations.
* Generated results can be edited.

### 💬 AI Workplace Chatbot

* Interactive AI-powered workplace assistant.
* Responds dynamically to user prompts.
* Supports workplace-related questions, tasks, and productivity requests.
* Responses are generated by AI rather than predefined templates.

### 🎨 User Interface

* Modern SaaS dashboard design.
* Light grey and dark professional colour palette.
* Sidebar navigation.
* Responsive layout for desktop, tablet, and mobile.
* Clean cards, forms, buttons, and input components.
* Loading and error states for AI requests.
* Responsible AI disclaimer.

## Technologies and Tools Used

* **React** – Frontend application framework
* **TypeScript** – Type-safe development
* **Vite** – Development and build tooling
* **Tailwind CSS** – Responsive styling and UI design
* **AI API/Model** – Dynamic AI-generated responses
* **Lovable** – Application development and prototyping
* **GitHub** – Source code management and version control

## Setup Instructions

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure AI Access

Configure the required AI model/API connection according to the project's environment configuration.

Do not commit API keys or other credentials to GitHub.

### 5. Start the Development Server

```bash
npm run dev
```

The application will be available through the local development URL provided by Vite.

### 6. Build for Production

```bash
npm run build
```

## Data & Privacy

The application is designed without a backend database or persistent storage. User inputs and generated outputs are not intended to be permanently stored by the application.

AI-generated content should always be reviewed and verified before being used for professional purposes.
